# WOLFESE DISTRICT

Telegram shop foundation for WOLFESE.

Includes:
- aiogram 3 Telegram bot
- PostgreSQL
- products and account inventory
- orders
- YooKassa SBP / bank-card payment creation
- payment webhook
- automatic account delivery
- suspicious-order flag
- admin statistics
- aggregated payment analytics by bank when the provider supplies bank data

Never commit `.env` or real secrets to GitHub.
